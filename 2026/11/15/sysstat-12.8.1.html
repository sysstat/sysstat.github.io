Sysstat 12.8.1

15 Nov 2026

This version fixes two security flaws which could happen with crafted saDD daily datafiles used by sar/sadf. See corresponding commits for details. This version also adds support for NDJSON (Newline Delimited JavaScript Object Notation) output for all sysstat commands (sadf, iostat, mpstat, pidstat, cifsiostat and tapestat). Many other small fixes are included here too.
